# Changelog

All notable changes to `xuan-calendar` are documented here.

## [0.1.0] - 2026-08-18

### Added

- Initial public release.
- Gregorian and Julian date conversion helpers.
- Vietnamese and Chinese lunisolar calendar conversion.
- Explicit fixed-offset time zones and day-boundary policy.
- GanZhi year, month, day, and hour calculations built on `xuan-cosmology`.
